What the order is doing

    GroupPitchesBasesRuns

    How runs are counted. One continuous inning, no outs. Each hit moves every runner forward by the same number of bases as the hit (single 1, double 2, triple 3, home run 4); a runner scores on reaching home, and the run is credited to the pitch that brought them in. Room mood is a running average: each pitch moves the room part of the way toward its own impact, and "room memory" sets how much of the previous mood carries over. "With runs" adds the runs a pitch drives in to its hit, capped at 4. Your lineup is saved in this browser; the share link carries it in the URL and is not stored on any server.
