# Game OS

Game OS is a set of connected tools that help indie game studios plan, price, test and launch a game on Steam. It runs at [llamagriffin.com/game-os](https://llamagriffin.com/game-os), by Llama & Griffin.

- **New here?** Start with [docs/GETTING-STARTED.md](docs/GETTING-STARTED.md): run it on your own computer and send changes.
- **How it fits together:** [docs/PROJECT-GUIDE.md](docs/PROJECT-GUIDE.md): the aim, where things live, the tools, open work and the rules.

All live code is in [`vercel/`](vercel/). Work happens on the `game-spine` branch.
